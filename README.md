# ClearFrame Windows & Glass

A responsive one-page website concept for a made-to-measure uPVC and aluminium windows, doors, and toughened glass business.

## Run locally

Open index.html in a browser. The site uses plain HTML, CSS, and JavaScript, with DM Sans loaded from Google Fonts.

## Before launch

- Replace the ClearFrame placeholder brand with the company’s real name and logo.
- Update sample contact information, service area, and social links.
- Connect the quote call to action to a real contact form, email, or CRM.
- Replace CSS illustrations with approved project photography when available.

## GitHub Pages

This static site can be hosted directly from the repository root using GitHub Pages.
